## The two findings worth carrying past this milestone

**A wrong comment became a wrong number on screen.** `adapter.ts` recorded mainnet ids
`0x00/0x02/0x10/0x20/0x23` as charging 950 000 drops. The probe says `0x23` charges 500 000 —
four ids, not five. The mock copied *the sentence* rather than the JSON, so the gallery
rendered a fabricated chain read on the one screen whose stated purpose is that fees are read
and never defaulted. It reached six places, and the sixth was a test asserting the fabricated
number: **a test can hold a bug still.** When recording an observed value, copy from the
evidence file, never from prose about it.

**Three assertions could not fail.** The sharpest, `toContain('0 drops')`, passed off an
unrelated `"1000 drops"` fee row — leaving this milestone's headline honesty rule with no
falsifiable coverage in either direction. Substring assertions over whole-card text are
worthless for these rules; scope to the row and use exact equality, then mutation-check.

## Decisions taken (2026-08-14)

- **`buildInstructionPayment` stays separate from M1's `buildDirectMintPayment`.** They share
  twelve lines of object literal and differ in the safety-bearing parts — memo encoding versus
  32 validated pre-encoded bytes, and a deliberately distinct `ledgerFeeDrops` name because
  `InstructionPlan.feeDrops` is a different number. Merging restores the hazard the file exists
  to prevent. Documented on both sides.
- **The agent-vault refusal is kept, not deleted.** Unreachable today only because all three
  agent-vault instructions are `superseded` — a protocol standing, not a structural
  impossibility. A test pins that argument, so a change tells us rather than costing a payment.
- **The live evidence JSON is committed as the script wrote it**, overwrite and all, with the
  two facts it cost recovered from the chain rather than reconstructed.

## Known and deferred

- **The live script collides its per-run keys.** Both runs' `preflight` and `attest` phases are
  written under one key each, so run 2 overwrote run 1. Fix before the next milestone that
  drives two runs of one flow. `verify-smart-account-evidence.mjs` is the keyless re-read
  script if a recorded value is ever doubted again.
- **Nine `OperationTimeline` callers still leak the wall clock** into `RecoveryPanel`. Unlike
  `WithdrawCard` — fixed here, and the one place the bug was already live — they carry no clock
  prop at all, so the fix is an API change across nine published components. Out of M13's scope
  and deliberately not taken unasked.
- **M14 grounding is already read**: `MemoInstructionsFacet.sol`'s memo dispatch and its
  pinned-executor gate, noted during the M13 source pass.
