# M11 Staking Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: superpowers:subagent-driven-development
> (fresh subagent per task + two-stage review) — this milestone is driven
> **real-first against live Coston2**: the implementer **resolves the existing
> Flare staking contracts from the registry** and **reads the P-chain** (validators,
> limits, positions) to write correct code and fixtures. Steps use checkbox
> (`- [ ]`) syntax. Plan location follows the project convention (`.thoughts/plans/`),
> overriding the skill default. This repo is **not** a git repo in this session —
> treat "Checkpoint" steps as markers; skip the `git` call if it errors.

**Goal:** Ship a **staking** card as an installable kit surface — discover the live
Coston2 validator set, read the on-chain stake minimums and the account's P-chain
staked positions + mirrored vote power, **stake** (C→P export → P import →
`AddPermissionlessDelegator`), and later **return** (P→C after the ≥14-day lock) and
**claim** the **non-expiring** `ValidatorRewardManager` reward — the first capability
whose signed transaction is a **P-chain transaction, not an EVM/viem call**.

**Architecture:** Mirror the M8/M9/M10 stack, but split the substrate. All **reads**
are SDK-free: the P-chain reads (validators, min-stake, stake positions) are plain
JSON-RPC; the EVM reads (verifier limits, mirrored vote power, reward state) are viem.
The **write** (the four signed legs + the reward claim) is a P-chain transaction
issued by `@flarenetwork/flare-tx-sdk`, kept **out of the shipped runtime** behind an
injected **`PChainStakeExecutor`** seam — flarejs is a **devDependency** used only in
the live script, tests, and a reference executor (the `xrpl` precedent). The stake
lifecycle reuses the **canonical** `states.ts` + the shared `reconcileTo` walker; the
≥14-day return is the delayed `awaiting_external → action_required → succeeded` leg
already forged in M7/M10. `portfolio.ts` flips its declared-unbuilt `stake` placeholder
to a real `observed | unavailable` position **once `stakeVerified`**. The staking
reward is a **fourth `ClaimKind`** on the existing `ClaimCard`.

**Tech Stack:** TypeScript, viem (peer), React, vitest, Turborepo/pnpm.
`@flarenetwork/flare-tx-sdk` (→ `@flarenetwork/flarejs ^4.1.1`) as a **devDependency**
behind the executor seam. P-chain PVM JSON-RPC for reads; `AddPermissionlessDelegator`
for the stake; `ValidatorRewardManager` (`GenericRewardManager`) for the non-expiring
reward.

## Global Constraints

- Production source files **< 300 lines**; split before writing (CLAUDE.md).
- **The shipped runtime stays viem-only.** No `packages/*/src` file imports
  `@flarenetwork/flare-tx-sdk` or `flarejs`. The SDK appears only in `scripts/`,
  `test/`, and the reference executor. `publint` + build carry no flarejs.
- **Never fake protocol reality.** A submitted delegate is `awaiting_external`,
  **never** `succeeded`; `succeeded` is entered **only** from reading the on-chain
  P-chain stake position (`getStake`/`getStakesOf`) back. An unknown outcome is never
  `failed`; an absent read is `unavailable`, **never a fabricated zero**. Mock mode is
  explicit/labelled, never a failure fallback.
- **The stake is irreversible for ≥14 days.** The value-lock + the lock clock are
  surfaced as real, non-reversible value commitment **before** signing (the rNat-burn
  precedent). The return + reward are **delayed, self-reconciling** legs.
- **Minimums are read live, never hardcoded.** amount ≥ 50k / ≤ max, 14-day ≤ duration
  ≤ 365-day come from `PChainStakeMirrorVerifier` / `platform.getMinStake` at plan time
  — never the doc table's figures.
- **Staking rewards do not expire.** `ValidatorRewardManager` has no expiry; never
  share M10's "rewards expire in 25 epochs" line.
- **Validators are live-read, never invented.** No NodeID literal ships in library
  source; a stake's `end` cannot exceed the chosen validator's active window.
- **`stakeVerified` gates every write and the portfolio flip.** It starts `false` and
  flips `true` only after a real broadcast + the confirming stake-position read. **If
  50k funding never lands, the broadcast carries declared-unbuilt** (`stakeVerified:false`,
  `stake` placeholder stays unbuilt) — the honest collapse-to-B (M8 precedent). No
  fabrication.
- **Secrets:** `.secrets/live-run.json` holds the dev key; keys are never logged,
  never in `--json`/evidence. Browser surfaces sign only via an injected executor and
  never hold a key.

### Harness mechanics (read before Task 0)

- **Never `cd` into a package** — the stage guard resolves the project root from the
  shell cwd and will block source writes. Use `pnpm --filter` from the repo root.
- **SPEC.md `## Files` manifest** (Task 0): every source file must be listed there
  before it is written. The section ends at the next `##`/`###` of any depth — insert
  only flat bullets, never a subheading.
- **Test lock**: each test file's mtime is compared to SPEC.md's; one SPEC.md write
  unlocks every test file once. Batch test-file creation behind the one Task-0 SPEC
  write; never touch SPEC.md just to unlock.
- **react-ui imports `@flare-kit/react` from dist** — a core/hook change needs
  `pnpm build` before react-ui (and any live script that imports core) sees it.
- **`applyTransition` silently drops its patch** on an illegal hop — every reconciler
  must **walk the `states.ts` table** via the shared `reconcileTo` (BFS `pathTo`),
  never jump states. Import `reconcileTo`/`waitSince`/`advance` from `reconcile.ts`;
  do not re-implement (the `bridge-states.ts`/`gasless-states.ts`/`delegation-states.ts`
  precedent).
- **flarejs is a devDependency only** (Task 0 adds it). The shipped read path
  (`pchain-rpc.ts`) is plain JSON-RPC + a small local bech32 helper; the SDK is used
  only by the reference `PChainStakeExecutor` in the live script / tests.
- **P-chain address derivation:** `pchain-rpc.ts` reads are keyed by a P-chain
  (`costwo…` bech32) address, derived SDK-free from the account public key via a small
  local helper (`ripemd160(sha256(pubkey))` → bech32/`costwo`). If the exact encoding
  proves to need the SDK, the **dev probe** may source the address from the SDK while
  the **shipped** reads stay address-parameterized (never SDK-coupled).
- **No contract deploys this milestone.** The EVM contracts exist; Task 1 resolves and
  snapshots `PChainStakeMirror`, `PChainStakeMirrorVerifier`, `ValidatorRewardManager`
  from `FlareContractRegistry` (`0xaD67FE66660Fb8dFE9d6b1b4240d8650e30F6019`). Task 2's
  parity test asserts the snapshot against a live registry read.
- **The stake broadcast is carried, not forced.** Task 6 runs the keyless reads
  always; the value-locking broadcast is gated on **≥50,000 C2FLR funding + Abu's go**.
  If unfunded, M11 closes with `stakeVerified:false` and the built path — the return +
  reward are recorded as carried legs (the Firelight/M10 pattern). Task 13 records the
  carry in `state.json`.
- **state.json bump** at close (Task 13) via a JSON load/mutate/dump script — never
  hand-edit.
